# 攻擊演出動畫

這裡放 80 支角色攻擊演出的動態 WebP，**檔名就是角色名稱**，例如：

    雷霆權杖・宙斯.webp
    獨眼龍・伊達政宗.webp

這些檔案是由 Google 雲端硬碟裡同一批 MP4 轉檔而成，每支壓在 2 MB 以內
（寬 270～360 px、每秒 8～12 格，畫質依檔案大小自動調整）。

遊戲會先找這裡的檔案；找不到時自動改用原本 Drive 上的網址。

## 之後要新增或替換動畫

1. 檔名改成角色名稱（和遊戲裡顯示的名稱一字不差，包括中間的「・」）。
2. 單檔最好在 2 MB 以內，手機載入才快。
3. 到 GitHub 網頁進入 `assets/anim` 這個資料夾，按 **Add file → Upload files**，
   把**檔案本身**拖進去（不要拖整個資料夾），再按 **Commit changes**。
   GitHub 網頁一次最多 100 個檔、每個檔 25 MB 以內。
