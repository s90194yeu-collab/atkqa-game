關於答對率等於攻擊力這件事　規則書

答對率就是你的攻擊力。這不是打字快就能贏的遊戲，讀懂題目才是。

一、基本流程

  • 全場分為 3 個回合，每回合題數＝題庫總題數 ÷ 3。
  • 每題流程：作答 → 取得發動權 → 選擇行動 → 觀看攻防 → 確認解析 → 下一題。
  • 作答過的題目不會再出現；答錯的題目會在下一回合再出一次（每題最多重來一次）。
  • 每回合結束可存檔。回合進行到一半也能按左下角的 💾 暫存，下次登入從同一題接續； 每一題開始時，這台裝置也會自動備份一次。
  • 送出答案前會再確認一次，避免手機誤觸。

二、發動權

  • 發動權＝（答對選項數 − 誤選數）÷ 正解數，未作答為 0。
  • 攻擊傷害直接乘上發動權；特技需要 50% 以上才發動得起來。
  • 防禦的減傷幅度也隨發動權遞增，全對才有完整效果。
  • 發動權 0％ 時所有招式都會鎖住──這一題你只能使用精神指令，或直接進入下一題。
  • 連續全對可累積 連擊，每層 +8% 傷害，最多 5 層，答錯即歸零。

三、三招各司其職

  • 攻擊：造成傷害，受屬性相剋、命中率與會心影響。威力越高命中率越低，但期望傷害仍隨威力遞增——高威力永遠是划算的，只是比較不穩。
  • 群體攻擊：一次打到所有敵人，但對每個目標只有 72% 傷害，命中率再 −18%，而且打不出會心。
  • 防禦：大幅減傷，並有機會反擊；防禦型角色反擊率再 +20%。
  • 特技：提升攻防、蓄力、回復，或讓對手中毒、失準、弱化。

四、八屬性相剋

剋制時傷害 ×1.5，被剋時 ×0.5。選角前先看看對手的屬性。

  • 五環相剋：火 → 風 → 土 → 雷 → 水 → 火（箭頭方向為「剋」）。
  • 光 ⇄ 冥：兩者互剋，彼此傷害都加成。
  • 無：不剋任何屬性，也不被任何屬性剋，數值換取穩定。

五、陣營共通被動

選了哪個陣營，整場都會帶著這個效果，不需要發動。

  • ⚡ 神域　神威：開場 SP +4
  • 🛡️ 誓約　誓約之盾：防禦招的減傷效果再 ×0.5
  • 🏯 亂世　下剋上：攻擊 ×1.2、命中 +10
  • 🐉 逐鹿　兵法：先攻判定 +8、閃避 +5%、會心 +8%
  • 🍶 梁山　義氣：受擊時反彈 15% 傷害
  • 🎓 學府　預修學分：每一題 SP +2
  • 🌿 淺山　野性自癒：每回合回復 5% 體力

五之二、解鎖貓與收集獎勵

  • 每個陣營都藏著一隻貓，未解鎖時在該陣營分頁顯示成 ？？？ 卡片。
  • 解鎖條件：用該陣營的角色完整打完三個回合，累積到該陣營可選角色的半數。 中途被擊倒或提早結束都不算。點那張 ??? 卡片可以看目前進度。
  • 貓的整體強度約為一般角色的 112%，代價是不能進化，也不會有夥伴來合體。
  • 七隻全部解鎖之後，往後不論使用哪一位角色，每場都可以額外使用一次 🐾 直接解題：牠們會替你把正解圈出來。

六、特色能力

每位角色都有一個 一場一次 的特色能力。換乘或變形後可以再使用一次，所以三階角色一場最多能發動三次。

其中兩個特別吃屬性與陣營：天敵直覺在你的攻擊屬性剋制對手時再 ×1.4、對手屬性被你剋制時受創 ×0.75；宿敵對上特定陣營時傷害 ×1.5、受創 ×0.7。

七、精神指令

  • 答題累積 SP：全對 +3、部分答對 +1。每個定位可用的指令不同。
  • 熱血（×2.0）與魂（×2.5，必會心）可以疊加，兩個都用是 ×3.5，代價是 13 SP。
  • 發動權 0 的那一題，精神指令仍然可以正常使用。

八、合體支援

攻擊或防禦時有 14% 機率 由同一小隊的夥伴登場：合體攻擊傷害 ×1.65；合體防禦再減半傷害，且反擊率大幅提高。

夥伴只會從同一個小隊裡找，例如三國的角色只會和三國的角色合體。

九、角色定位

  • 攻擊型：傷害最高，血量偏薄。
  • 防禦型：減傷與反擊最強。
  • 耐久型：血量最厚，適合久戰。
  • 幸運型：高會心、高閃避。
  • 速攻型：命中穩定、偶爾閃避。
  • 均衡型：各項平均，最好上手。

十、換乘與變形

  • 換乘條件大多是正向的：連續答對幾題、撐過幾題、體力保持在高檔。只有少數角色是體力低落或累積受創才爆發。
  • 換乘會回復體力並更換全部招式，有些角色連定位都會變（例如林沖從防禦型變成攻擊型）。
  • 部分角色是三階成長，例如宋江：鄆城押司 → 及時雨 → 梁山之主。
  • 部分角色覺醒後可自由切換形態，例如呂布的方天畫戟／赤兔／強弓。切換不消耗回合，體力比例保留，隨時可以換回來。
  • 選角畫面會標出每位角色的換乘條件，戰鬥中也會顯示在戰術面板上方。

十一、計分

  • 答題得分：每題最高 100 分（依發動權比例）。
  • 擊倒對手 +200，最高連擊每層 +60，每完成一回合 +150。
  • 最終再加：殘存體力 ×3、獲勝 +500。

十二、成長系統

  • 題型熟練度：八大題型各自累計全對題數，滿 5／15／30／50／80 題升到 Lv1～Lv5。 出到這類題目時，每一級出招傷害 +3%（Lv5 為 +15%）。
  • 典故卡：用一位角色完整打完三回合，就解鎖他的典故卡與招式典故；同一位角色通關 3 次升銀框、5 次升金框。
  • 成就徽章：共 18 個，例如十連全對、完美回合、以一敵三、群英薈萃，在首頁「我的成長」點徽章就能看條件。
  • 全班討伐：每一課、每一班各有一隻討伐目標。全班的作答會累計成傷害（全對一題 10 點）， 打倒之後，全班在這一課開場 SP +5。
  • 錯題道場：錯題本裡的題目會化身菁英怪，一次最多 20 題。全對就訂正成功，題目從錯題本移除。道場不計學期積分。
  • 每週活動：老師開放的限時活動會顯示在首頁最上方，例如指定屬性傷害加成、開場 SP 增加、指定課次分數加乘。

典故圖鑑

用一位角色完整打完三回合，就能解鎖他的典故卡，讀到每一招背後的故事。同一位角色通關 3 次升銀框、5 次升金框。
